A viewer is one half of the connection

A VNC client displays and controls a desktop supplied by a VNC server. Lantern is the client on your Mac. The other computer still needs a running, compatible server, such as TightVNC, and permission to accept your connection.

Installing a viewer does not turn on remote access at the other end. A computer offering only RDP or a vendor’s cloud connection is not automatically a VNC server.

Check these before connecting

  • Your Mac: Apple Silicon and macOS 13 or later. The supplied app is arm64; Intel Macs are not supported.
  • The server: its actual TCP listening port and VNC password when authentication is required. Find… can discover servers on the current private IPv4 LAN; you can also enter an address manually. Port 5900 is common, but use your server’s setting.
  • The route: a reachable trusted LAN, or a VPN/SSH tunnel you establish separately. A firewall or isolated guest Wi-Fi can block access.

A server’s VNC password may differ from its operating-system account password. A Lantern account is not required. In the finder, a single result is selected automatically. Confirm a friendly alias with Save Computer to add it to your device list. Select Remember password if you want macOS Keychain to retain the VNC password after a successful connection. All Keychain reads, saves, and removals forbid authorization dialogs. Errors appear inline; a failed save turns Remember password off, and inaccessible older items are left unchanged. Manual VNC-password entry is always available. Current ad hoc builds can lose access to saved Keychain passwords across app updates; a secure fix has not yet been verified. For connection errors, use the troubleshooting guide rather than changing unrelated Mac display settings.

Use a trusted route.

This build does not encrypt VNC traffic or establish a tunnel. Keep an unencrypted VNC service off the public internet; use a separately secured route when needed.

See the detail, then reach the edges

New connections open in Fit to Window. Lantern remembers the last viewing mode and picture-quality preset for each host and port. It also restores window size and position across launches, adjusted when needed to remain reachable. When Fit makes text too small, Auto (Readable) keeps a large remote desktop from shrinking below 100% in drawable/backing pixels. A large desktop can extend past the visible area. Use the native scroll bars or turn on Hand to drag, scroll, or use arrow keys to move your local view. Escape leaves Hand mode.

Choose Fit to Window for the whole image, or an explicit zoom for larger text. With Hand off, normal wheel scrolling controls the remote app. None of these viewing controls changes the server’s resolution. The display and navigation guide explains Retina scaling and the available shortcuts.

The RTT line below connection status reads the current TCP round-trip estimate once a second while connected, without extra probes. It does not measure input-to-screen delay; capture, encoding, or rendering can still cause lag. See what RTT, idle, and tunnel endpoints mean.

Match the viewer to the job

Lantern fits when…

  • You have a reachable VNC server and want direct access from an Apple Silicon Mac.
  • You need remote display, keyboard/pointer control, and optional text clipboard sharing.
  • You prefer a free viewer without a Lantern login, subscription, or expiry.

Plan for another setup when…

  • Your Mac is Intel-based, or the remote service is RDP rather than VNC.
  • You need a cloud relay, remote audio, file transfer, or printing.
  • You need built-in transport encryption or an Apple-notarized production app.

For Mac-to-Mac access, Apple’s built-in Screen Sharing is another option. Apple documents connecting to another Mac on your network; follow its setup and permission guidance.

Know which build you are opening

The current download is 1.1.0 Preview 6 · build 10. It reduces local framebuffer and GPU texture copying for partial updates and can service queued input while a screen update is still arriving. Decoded pixel quality, picture presets, and server resolution are unchanged. This is a local processing improvement, without a change to VNC network compression or a Wi-Fi speed guarantee.

It is ad hoc signed and has not been Apple-notarized. Physical external-display transitions and the full manual hardware matrix remain unverified. It should be evaluated as a preview, without a performance or compatibility guarantee.

The app remains free to use, with no account, subscription, expiry, or payment gate. Read the opening and setup instructions, download from the project, and review website privacy choices. The complete corresponding source is available in the public repository.
