# Preview 2 review and publication checks

Reviewed first-party application, transport wrapper, build/package scripts, website interactions and Wiki links. Vendored protocol libraries were not independently audited. The read-only review found source packaging included prior downloadable archives; the source package now excludes docs/downloads. The final source ZIP was inspected for complete vendor sources, archive traversal and excluded prior downloads.

Preview 2 changes the original app icon, build/channel metadata and the Help → Send Feedback destination. The renderer, viewport and input code retain Preview 1's tested implementation. Preview 2's actual AppKit controller harness passed 3,238 assertions; arm64 and strict ad hoc signature checks passed. Preview 1's recorded geometry, native Metal/input and protocol evidence remains linked from the README. External-display hardware transitions and notarization remain incomplete; this is an early-access preview.

Website checks cover all seven HTML pages, 188 local links/assets/anchors, unique IDs, JavaScript syntax, privacy opt-outs, storage fallback, local QA isolation, failed submissions, preserved inputs, idempotent retries and success receipts. Owner dashboard rendering uses text nodes for feedback and rejects unsafe issue URLs. Five service test groups use real SQLite migrations for anonymous origin/input validation, private API access, event deduplication, one vote per browser, owner-only feedback, dataset isolation and honest error responses. Built Worker tests also exercised actual local D1 persistence.

Complete visual browser navigation could not be performed because the computer/browser-control runtime was unavailable. HTTP and scripted DOM checks are not a replacement for that coverage. The app remains a preview and no universal bug-free claim is made.
